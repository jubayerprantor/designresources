## How to Contribute

This is a community-driven collection powered by **[GiveBack2People](https://giveback2people.github.io/)**, open to contributions. If you know a great resource that belongs here:

1. **Fork** this repository on [GitHub](https://github.com/GiveBack2People/designresources)
2. **Add** your resource to the appropriate category file in `docs/` (e.g., `docs/typography.md`, `docs/stock-photos.md`) following the existing table format
3. **Submit a Pull Request** with a brief description of what you're adding

> **Quality Standards:** General resources must be free or offer a functional free tier (paid-only tools belong strictly in Creative Marketplaces and must be established, recognized industry platforms). Duplicate or broken links will be declined.

**[View Contribution Guide →](/contributing)**
