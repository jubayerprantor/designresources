# How to Contribute

Thank you for your interest in contributing! This is a community-driven design resource collection under **GiveBack2People** — all additions go through a pull request review to ensure quality.

---

## Steps to Contribute

1. **Fork the Repository**
   Click the **Fork** button on [GitHub](https://github.com/GiveBack2People/designresources) to create your own copy.

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/YOUR-USERNAME/designresources.git
   cd designresources
   ```

3. **Create a New Branch**
   ```bash
   git checkout -b add-my-resource
   ```

4. **Add Your Resource**
   Find the appropriate category file in `docs/` (e.g., `docs/typography.md`, `docs/stock-photos.md`, `docs/code-frameworks.md`) and add your resource to the relevant table:
   ```markdown
   | [Resource Name](https://example.com) | Brief, accurate description of the resource. |
   ```

5. **Commit & Push**
   ```bash
   git add docs/
   git commit -m "Add: Resource Name to Category"
   git push origin add-my-resource
   ```

6. **Open a Pull Request**
   Go to the original repository and open a Pull Request describing what you've added.

---

## Guidelines

- **Free or meaningful free tier (General Categories)** — resources in general categories must be 100% free, open source, or have a functional free tier. Paid-only tools in these sections will be declined.
- **Creative Marketplaces Exception** — paid-only resources belong strictly in [Creative Marketplaces](/marketplaces) and must be established, recognized, top-tier industry platforms (e.g., Envato Elements, Motion Array, Artlist). Personal storefronts, newly created sites, or unverified commercial listings will be declined.
- **Working links only** — verify the site is live and uses HTTPS before submitting
- **Accurate descriptions** — objective summaries without marketing hype or affiliate tracking parameters
- **No duplicates** — check if the resource already exists before adding
