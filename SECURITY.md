# Security Policy

## Supported Versions

As this is a static documentation portal, only the current `main` branch deployed to GitHub Pages is supported with security updates.

| Branch | Supported          |
| ------ | ------------------ |
| main   | :white_check_mark: |

## Reporting a Vulnerability or Malicious Link

The safety and security of our visitors and community members is paramount.

If you discover a:
- Compromised or malicious external link (malware, phishing, spoofing)
- Dependency vulnerability in our static site generator
- Sensitive credential or unauthorized data disclosure

Please do **NOT** disclose it via public issues or comments.

Instead, please report it privately:
1. Open a **Private Security Advisory** on GitHub under the **Security** tab of this repository.
2. Or open a confidential issue directly with the organization administrators at [GiveBack2People](https://github.com/GiveBack2People).

We will investigate immediately, remove any offending link, and update dependencies promptly.
